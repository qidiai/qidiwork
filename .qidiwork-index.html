首次安装提示
1. 下载后若 Windows 弹出蓝色 SmartScreen 提示（"Windows 已保护你的电脑"），点击「更多信息」→「仍要运行」即可——这是未购买代码签名证书的正常现象。
2. 安装过程需要一次管理员授权（UAC 弹窗点「是」）。
3. 安装完成后程序自动启动，模型 API Key 在设置面板中填写即可使用。
