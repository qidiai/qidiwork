## 9. 已知坑（都踩过）

| 坑 | 处理 |
|---|---|
| sccache 崩 → `could not compile` | 构建前 `set RUSTC_WRAPPER=` |
| 打包主二进制选错 | `mainBinaryName` + `[[bin]]` + `default-run` 三者必须一致；CLI 已拆 crate |
| 模板 `document.xml.rels` 缺 styles 关系 | WPS 静默丢样式、TOC 报"未找到目录项"；有 `doc.styles_link` 断言 |
| OOXML 子元素顺序 | `verify` 内置 6 张序列表（`styles.element_order`/`doc.element_order`） |
| WPS 另存重写样式 | 不要用 WPS 保存过的 docx 当 golden |
| `x509-parser` 本机缓存缺失 | 离线构建会断；首版用"整证书 DER pin"可绕 |
| 中文路径 pre-commit 漏扫/二进制误报 | 文本类提交正常；二进制用 `--no-verify` 并人工扫 |
| 页数只能用渲染器 | `pages::measure` 走 WPS COM，90s 超时，不关用户实例 |

## 10. 关键决策（勿反复）

- 版式真值 = **Word 模板**，代码只填内容；不重建样式。
- 运行期**零外部运行时**（不依赖 Python/Node）；图表生成属于写作期。
- 图件来源：**效果图可外部生图**（`{ai}` 标注）；**平面图必须来自项目图纸**；横道图原生表格。
- 页数上限：**招标 > 用户 > 询问**，无默认值。
- 单个 Markdown 文件：`#`=书名、`##`=章；项目模式一章一文件，首行可为 `# 一、…` 或纯文本。
- 更新必须签名；未配置公钥时显示"未验证"且不自动运行。
