## 3. 关键约束（审计结论，必须遵守）

1. **断言分层**：`styles.xml` 断样式参数（`w:sz`/`w:spacing`/`w:ind`/`w:color`/`w:shd`/`w:tblBorders`）；`document.xml` 断 `w:pStyle` 引用、`w:pgSz`/`w:pgMar`、图片/图注计数。不要对 `document.xml` 断言字号/行距/颜色。
2. **计数用** `rg -o '<w:drawing' file | wc -l`，不要 `rg -c`（document.xml 通常整篇一行，`-c` 恒为 1）。
3. **首行缩进**用 `w:firstLineChars="200"`（“2 字符”语义）；`w:firstLine="480"` 只作 12pt 近似备注。
4. **页数**：P0a 只记录“同一输入 + 同一渲染器 + 同一设置”的基线；**不要**用字符数÷每页字数估页；页数目标 P1 才启用。
5. **TOC/页码**：Word/WPS 打开 → 更新域 → 导出 PDF 再计页；LibreOffice headless 不更新 TOC，偏差要单独标注。
6. **图片段落**：P0b 做图桌时，图片段落用 `w:spacing lineRule="atLeast"` 或单倍行距防吞图（R-022）。
7. **模板程序化生成**：Word/WPS 只复核、不手编；改样式改生成器再重生成，版本号冻结。
8. **不写 manifest**：`bid_export_docx` 只写 `.docx` 并返回路径；登记走 `card.py`。
9. **不推送**：本地 commit 即可；推送需用户确认。
10. **不扩大范围**：P0a 只做最小闭环；遇到方案冲突先读审计报告。
