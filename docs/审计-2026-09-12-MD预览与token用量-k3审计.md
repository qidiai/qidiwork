## k3 原始结论

总评:**GO with fixes**

Blocker: 无

Warning:

1. **MdPreview 切换同类型文件不刷新(正确性)** — `PreviewPane.vue` 未设 `:key`;`MdPreview.vue` 仅 `onMounted(load)` 加载一次。先后打开 a.md、b.md 时 Vue 复用组件实例,界面停留在 a.md 内容。修复:各预览组件加 `:key="task + ':' + name"`(顺带覆盖 docx/xlsx/pdf 同型切换)。

2. **TurnUsage 的 meta 无大小上限(防御纵深)** — bridge.rs 中 `_meta` 任意 Value 整体 clone + emit 推给 webview,无截断。建议 >64KB 记 warn 并丢弃,仅发 TurnCompleted。

3. **broadcast Lagged 可静默丢 TurnUsage/TurnCompleted,与 useAgent.ts 头部不变量注释矛盾** — 展示流为 broadcast(有损);丢 TurnUsage 仅 chip 缺失,丢 TurnCompleted 会 busy 卡住(既存风险)。useAgent.ts 头部"传输层不丢帧"注释与 BridgeEvent 实际走 broadcast 失实。建议:Lagged 记日志 + 修正注释。

4. **handleLinkClick 吞掉 mailto 链接(与 PURIFY 白名单不自洽)** — ALLOWED_URI_REGEXP 放行 mailto:,点击处理只对 https? 调 openUrl,mailto 点击无反应。

Note(摘要):

1. XSS 渲染链闭环通过:显式 ALLOWED_TAGS(无 img/svg/style/iframe)、ALLOWED_ATTR 仅 href、URI 仅 https?/mailto、强制 target=_blank+noopener,点击走系统浏览器。
2. 链路顺序与错误路径通过:同任务顺序 send 保序;错误路径不发 TurnUsage;pendingUsage 每回合无条件清理,无跨回合残留;30 分钟超时晚到应答按"无主应答"丢弃。
3. 多会话路由通过:按 session_id 入桶,后台会话互不污染;状态栏取活动桶口径。
4. 解析健壮性通过:camelCase 优先无误读;Number.isFinite 挡 NaN;cost>0 才收符合 fail-close(代价:真实 $0 回合显示为不可信,可接受的保守取向)。小项:全零门槛不看 cost 会丢"仅成本非零"回合;fmtTokens 负数/fmtCost 极小值显示瑕疵。
5. office_read_file 校验链无绕过;2MB 前端上限在 base64 传输+解码之后才判定(浪费但非安全问题);2MB 渲染数百 ms 级可接受。
6. 畸形 _meta 全部降级不上屏;mock 内核零噪音。
7. 状态语义可接受:恢复不清累计、进程重启才清零,与"本会话"(本 UI 进程视角)自洽。
8. 挂载盲点:回合无任何 assistant chunk 时(立即报错)累计计入但 chip 缺失,显示取舍,存照。
