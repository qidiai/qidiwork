新发现问题:

1. `gui/src/services/sheetPreview.ts:18,51` + `XlsxPreview.vue:load` — **模块级 `cachedWb` 单例与异步 load 存在串档竞态**:A 组件在 `await invoke` 期间被卸载(任务切换 `closeAllPreviews`),其 `load()` 仍会继续执行 `parseWorkbook` 覆盖 `cachedWb`,污染已挂载的 B 组件——B 再点 sheet 会渲染 A 的工作簿或抛「工作表不存在」。且 `showSheet`(XlsxPreview.vue:70)对 `renderSheet` 抛错无 catch,点击静默失败。建议:workbook 引用由组件实例持有(`parseWorkbook` 返回 wb 而非写全局),`showSheet` 包 try/catch 落入 error phase。

2. `gui/src/services/sheetPreview.ts:51-52` — 截断用**绝对行号**:`endRow = min(total.e.r, 499)` 未计入起始行 `total.s.r`。数据区从 500 行以后开始的 sheet(`s.r > 499`)会得到 `e < s` 的非法 range,渲染为空表且 `truncated` 标志也错。建议 `endRow = min(total.e.r, total.s.r + MAX_SHEET_ROWS - 1)`,cols 同理。

3. `gui/src-tauri/src/skills.rs:52-55` — 引号剥离只认双引号:`description: '标书编写'`(单引号)会带引号原样展示。建议对称处理 `'`。

4. `gui/src/composables/useSkills.ts:21-30` — `initSkills` 失败后无任何重试入口(仅 `WorkspaceSidebar.onMounted` 调一次),首次 `skills_list` 失败则整个会话技能面板恒为空且提示语("未发现技能")与「加载失败」无法区分。建议空态加重试按钮或区分错误文案。

一句话结论:激活链/CSP/spawn_blocking/frontmatter 解析均经得起复核,唯 xlsx 预览的 workbook 全局缓存竞态(1)和截断 range 边界(2)是两个真实漏网缺陷,建议修复后合入,3/4 为可延后的打磨项。
