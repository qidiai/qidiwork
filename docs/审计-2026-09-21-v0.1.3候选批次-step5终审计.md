- [MEDIUM] gui/src-tauri/src/transcript.rs:245-250 - `tail_page` 在 seek 窗口起点恰好位于行边界时，会错误丢弃一条完整消息行，且全局行号空间出现 off-by-one。
  证据: 
  ```rust
  let s = match s.find('\n') {
      Some(i) => s[i + 1..].to_string(),
      None => String::new(),
  };
  (s, prefix_lines + 1)
  ```
  当 `size - TAIL_WINDOW_BYTES` 正好落在某行行首（前一字节为 `\n`）时，窗口内第一行是完整行，但上述代码无条件将其丢弃；同时 `base_line = prefix_lines + 1` 假设窗口起点总在行中，导致行边界时返回数据的全局行号与实际不符。测试 `tail_seek_drops_partial_first_line_when_truncated` 未覆盖此边界。
  建议: 移除无条件丢首行的 `s.find('\n')` 逻辑，将 `base_line` 改为 `prefix_lines`，依赖 `parse_jsonl` 对不完整首行的坏行跳过（已实现的容错）；或读取 `end-1` 字节判断是否在行边界，仅在行中时才丢首行。

- [LOW] gui/src-tauri/src/transcript.rs:180-190 - `session_dir` 的 `cwd` 经 `percent_encode` 后，`.` 不编码，若 `cwd` 为 `..` 则编码结果仍为 `..`，`home/sessions/../<session_id>` 可穿越至 `home/<session_id>`。
  证据: 
  ```rust
  if b.is_ascii_alphanumeric() || matches!(b, b'-' | b'_' | b'.' | b'~') {
      out.push(b as char);
  }
  ```
  `session_dir` 注释声称“cwd 经 percent-encode 后是单个路径段,天然不可穿越”，但 `..` 字面量未被编码，存在理论越权读取。
  建议: 在 `session_dir` 中显式拒绝 `percent_encode(cwd)` 等于 `..` 或 `.` 的情况，或校验 `cwd` 必须为绝对路径。
