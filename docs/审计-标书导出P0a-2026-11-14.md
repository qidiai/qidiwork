## 4. 施工过程中的规格审计与返工（可追溯）

### 4.1 规格送检（派工前，只读审计席 `qwen3.8-flash-next-ms-222`）

审计席判 **NO-GO（5 处照抄必挂）**，全部采纳并修入规格后才派工：

| # | 问题 | 修法 |
|---|---|---|
| 1 | `<w:tag …/>` 是自闭合 → quick-xml 发 `Event::Empty`，只处理 `Start` 会拿到 0 个锚点 | 规格补 `Event::Empty` 分支（并保留 `Start` 兜底） |
| 2 | 断言"成品不含 `BID_DOC_TITLE`/`BID_CHAPTER*`"自相矛盾（只替换 `sdtContent`，外层包装保留） | 改为只断言 `BID_TABLE_ROWS`/`BID_FIGURE_SINGLE`/占位文本不存在 |
| 3 | `output_path` 缺 `#[serde(default)]` → fixture 反序列化 `missing field` | 加 `#[serde(default)]`，空值改由 `export()` 报错 |
| 4 | 模板 rels 若自闭合，`</Relationships>` 定位失败 → 含图导出必挂 | 生成器写显式闭合；`add_png` 加自闭合兜底 |
| 5 | `verify` 断言 `<w:sz w:val="4"/>`，但表格边框是属性写法 `w:sz="4"` | 断言改 `w:sz="4"` |

顺带修：`</w:sdtContent>` 长度 16→**15**；文档标题段沿用 `BidTitle1` 使 `BidTitle1` 计数 = 章数+1（断言与 `check.sh` 同步）；`apply_edits` 签名统一为 `BidResult<String>`（消除"返回 String 又要报错"的歧义，单独提交 `a9ead4d`）。
