## 二、各步关键事实

### 步骤 2:预览 Tab 激活链断裂(生产 e2e 才暴露的真 Bug)
- **现象**:点「预览」Tab 出现但永不激活,内容区永远显示占位文案。
- **根因**:`previewKey()` 生成无前缀 `task/name`,MainTabs 的 Tab key 是 `preview:task/name`,模板 `startsWith('preview:')` 永假。纯字符串约定,vue-tsc 与 deepseek 审计都测不出来。
- **修复**:previewKey 统一带前缀,注册表 key = Tab key 全链一致;另加 `activationSeq` 序号强制触发同 key 重开激活(step 审计 W2 加固,B1 类缺陷结构性封死)。
- **连带发现并修复**:`Cargo.toml` 缺 `custom-protocol` feature——`cargo build --release` 产物运行时仍加载 devUrl(localhost:5173),报"拒绝连接"。**此前项目从未真正走过生产构建路径。**
- **闭环 W2**:生产 CSP `style-src` 加 `'unsafe-inline'`(docx-preview 运行时注入样式;script-src 保持 'self')。
