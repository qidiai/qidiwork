## 2. 元数据规则（唯一真值）

`core.xml` 输出固定为：

```xml
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<cp:coreProperties xmlns:cp="http://schemas.openxmlformats.org/package/2006/metadata/core-properties" xmlns:dc="http://purl.org/dc/elements/1.1/" xmlns:dcterms="http://purl.org/dc/terms/" xmlns:dcmitype="http://purl.org/dc/dcmitype/" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance">
  <dc:title>{escape_xml(req.title)}</dc:title>
  <dc:creator></dc:creator>
  <cp:lastModifiedBy></cp:lastModifiedBy>
</cp:coreProperties>
```

- 不写 `dcterms:created/modified`（避免时间戳泄露）。
- 若包内无 `docProps/core.xml`，**不新建**（模板必然有；缺失时跳过，不报错）。
- 包内若有 `docProps/app.xml`，**不动**（模板未生成；将来若加，另议）。

## 3. CLI 契约

```bash
bid_export --input <req.json> --out <out.docx> [--template <template.docx>]
bid_export --check-only <docx>
```

- `--input`：`BidExportRequest` JSON（同 `fixture-minimal.json` 的请求部分；多余字段忽略）。
- `--template`：缺省 `env!("CARGO_MANIFEST_DIR")/resources/templates/bid-engineering-blue-v1.docx`。
- 成功：先打印一行 JSON 摘要 `{"path":...,"bytes":...,"chapters":...,"paragraphs":...,"tables":...,"figures":...}`，再打印 `EXPORT OK`，exit 0。
- 结构校验失败：打印 `CHECK FAIL` + 不合格 check 名列表，exit 1。
- 参数错误/读盘失败/校验请求失败：打印 `ERROR <原因>`，exit 2。
- `--check-only`：只跑 `verify(None)`，结构与上一行相同（`{"checks":N,"ok":true}` + `CHECK OK`）。
- 不引入新依赖；不用 `unwrap`（`main` 里可用 `match` + `std::process::exit`）。
