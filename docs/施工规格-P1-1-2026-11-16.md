## 1. Markdown 契约（唯一真值）

| 语法 | 语义 |
|---|---|
| `# 标题`（首个） | 文档标题（`BidExportRequest.title`）；后续 H1 忽略 |
| `## 文本` | 章标题；未编号时自动 `第N章 文本` |
| `### 文本` | 节标题（`Block::Heading{level:3}`）；未编号时 `N.M 文本` |
| `#### 文本` | 子节（level 4）；未编号时 `N.M.K 文本` |
| 空行分隔的普通文本 | 每段一个 `Block::Paragraph`；段内换行合并为空格 |
| `\| a \| b \|` + `\| --- \| --- \|` | GFM 表格 → `Block::Table`（首行表头，其余数据行） |
| `![图注](路径)` 单行 | `Block::Figure{layout: Single, items:[{path, caption:图注}]}` |
| 连续 3 行图片（行间无空行） | `three_up` + `per_image`（每张的图注取各自 `[]`） |
| `![图注](路径){wide}` | `wide` 布局 |
| 其它 | 忽略 HTML 标签；`\` 转义原样保留 |

**编号规则**：
- 中文数字仅覆盖 1–10（`一…十`），11 起用阿拉伯数字（`第11章`）。
- `##` 文本若已匹配 `^第.+章` 或 `^\d+[.．、]`，不再加前缀。
- `###`/`####` 若已匹配 `^\d+(\.\d+)*`，不再加前缀。
- 章节序号按出现顺序递增；`###` 的 `M` 在每章内从 1 递增。

**图片路径**：相对 Markdown 文件所在目录解析；不存在 → `Err("图片不存在: {path}")`。

## 3. 模型与渲染细节

```rust
// model.rs 新增变体（放在 Paragraph 之后）
Heading { level: u8, text: String },
```

`validate()`：`level` 必须 2..=4，`text` trim 后非空；否则 `Err("标题级别非法（2-4）")` / `Err("标题文本为空")`。

`fill.rs`：`Heading` → `paragraph.xml`，`{{STYLE}}` = `BidTitle{level}`，`{{TEXT}}` = escape(text)；不计入 `stats.paragraphs`。

`verify.rs`：不加新 check（Heading 由 `BidTitle2/3/4` 样式体现）；既有 24 条不变。
