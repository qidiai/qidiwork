# 施工规格：P1-5 横道图（原生表格，无图片无新依赖）

**日期**：2026-11-16
**目标**：`gantt` 代码块 → Word 原生表格横道图（可编辑、可打印、评委可核日期），**不生成图片、不新增依赖、不新增样式**。

---

## 0. 设计取舍

- 用 **表格** 而非图片：每行一个工序，每列一个时间桶（默认 7 天），覆盖的桶填 `#4877AC` 底纹。
- 复用既有样式：`tblStyle=BidTable`、所有单元格 `BidTableBody`（**不使用 `BidTableHeader`**，因此业务表计数 `doc.tables` 不受影响）。
- 不引日期库：`YYYY-MM-DD` → 天数用 civil-from-days 算法（纯整数）。
- 时间桶：跨度 ≤ 112 天用 7 天/桶；否则 14 天/桶；桶数上限 16（超限报错 `横道图跨度过大（>16 个时间桶）`）。

## 1. 模型（`model.rs`）

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GanttTask { pub name: String, pub start: String, pub end: String } // YYYY-MM-DD

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct GanttBlock { pub title: String, pub tasks: Vec<GanttTask> }

// Block 新增变体
Gantt(GanttBlock),
```

`validate()`：
- `tasks` 非空（否则 `"横道图至少需要一个工序"`）；
- 每个 `name` 非空；`start`/`end` 能解析且 `start <= end`（否则 `"横道图日期非法: {start}..{end}"`）；
- 标题可为空（导出时不加图注）。

## 2. Markdown 语法（`markdown.rs`）

````
```gantt 图4-1 施工进度横道图
2026-12-01..2026-12-10 | 塘底清淤
2026-12-05..2026-12-20 | 管网敷设
2026-12-15..2026-12-25 | 路基整平
```
````

- 围栏首行 ```` ```gantt ```` 后的文本 = 标题（可空）。
- 行格式 `开始..结束 | 工序名`；空行忽略；格式不符 → `Err("横道图行格式错误: {line}")`。
- 未闭合围栏 → `Err("横道图代码块未闭合")`。

## 3. 渲染（`fill.rs`）

1. 解析所有任务，求全局 `min_start`、`max_end`，跨天数 `span = max_end - min_start + 1`。
2. `bucket = if span <= 112 { 7 } else { 14 }`；`buckets = ceil(span / bucket)`，`buckets > 16` → `Err`。
3. 表格列：首列（工序名，宽 2600 twips）+ `buckets` 列（各 `(10546-2600)/buckets` twips 均分）。
4. 表头行：`工序` + 各桶起始日 `MM-DD`；正文行：工序名 + 每桶 `<w:tc><w:tcPr><w:tcW …/><w:shd w:val="clear" w:color="auto" w:fill="4877AC"/></w:tcPr><w:p><w:pPr><w:pStyle w:val="BidTableBody"/></w:pPr></w:p></w:tc>`（未覆盖的桶不加 shd）。
5. 表格用现有 `table.xml` 片段（`tblStyle=BidTable`），行片段复用 `table_row.xml`（`{{CANTS_SPLIT}}` 传 `<w:cantSplit/>`、`{{HEADER_FLAG}}` 传空）。
6. 标题非空 → 表格后加一段 `BidCaption`。

**覆盖判定**：任务覆盖某桶 ⇔ `task_start < bucket_end && task_end >= bucket_start`（桶按自然日切，从 `min_start` 起算）。
