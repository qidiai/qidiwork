## 4. B2：图模型 + 三布局填充 + 校验扩展

### 4.1 模型（`model.rs`，只改 Figure/Block 段）

```rust
#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq)]
#[serde(rename_all = "snake_case")]
pub enum FigureLayout { Single, Wide, ThreeUp }

#[derive(Debug, Clone, Copy, Serialize, Deserialize, PartialEq, Eq, Default)]
#[serde(rename_all = "snake_case")]
pub enum CaptionMode { #[default] PerImage, PerGroup }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FigureItem {
    pub path: String,
    #[serde(default)] pub caption: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FigureBlock {
    pub layout: FigureLayout,
    pub items: Vec<FigureItem>,
    #[serde(default)] pub caption: String,          // 组图注 / 单图缺省图注
    #[serde(default)] pub caption_mode: CaptionMode,
    #[serde(default)] pub ai_generated: bool,
}

pub enum Block {
    Paragraph { text: String },
    Table { header: Vec<String>, rows: Vec<Vec<String>> },
    Figure(FigureBlock),                            // ← 新形态（替换旧命名变体）
}
```

JSON 形态（fixture 用）：
```json
{"type":"figure","layout":"single","items":[{"path":"assets/image3.png"}],"caption":"图1-1 …","ai_generated":true}
{"type":"figure","layout":"three_up","caption_mode":"per_image","items":[{"path":"a.png","caption":"图2-1 …"},{"path":"b.png","caption":"图2-2 …"},{"path":"c.png","caption":"图2-3 …"}]}
{"type":"figure","layout":"three_up","caption_mode":"per_group","items":[{...},{...},{...}],"caption":"图3-1 现场平面示意"}
{"type":"figure","layout":"wide","items":[{"path":"gantt.png"}],"caption":"图4-1 施工进度横道图"}
```

**`validate()` 新增规则**：
- `items` 非空；`Single`/`Wide` 要求 `items.len()==1`，否则 `"单图/宽图只能有 1 张图"`。
- `ThreeUp` 要求 `1<=items.len()<=3`；不足 3 张时补空单元格（不拉伸、不报错）。
- `caption_mode=per_image` 且 `ThreeUp` → 每项 `caption` 必须非空，否则 `"三栏图桌逐图图注不能为空"`。
- `caption_mode=per_group` → `caption` 必须非空。
- `Single`/`Wide` + `per_image` → 图注取 `items[0].caption`，空则退到 `caption`，两者都空报 `"图注不能为空"`。

| `three_up` | `figure_3up.xml`：`{{CELLS}}` = 3 个 `<w:tc>`（不足补空 `<w:tc><w:tcPr><w:tcW w:w="3515" w:type="dxa"/></w:tcPr><w:p><w:pPr><w:pStyle w:val="BidFigureCell"/></w:pPr></w:p></w:tc>`）；每格 `图片段 + 图注段`（per_image）或 `图片段`（per_group，图注在表格下方 1 段） | 每格 `style.figure.cell_width_cm`（5.8） |

**图注规则（唯一真值）**：
- `per_image`：每张图一段 `BidCaption`；文本 = 该项 `caption`（single/wide 可回退 `caption`）；`ai_generated` 时追加 `style.figure.ai_label`。
- `per_group`：整组一段 `BidCaption`，文本 = `caption`（+ AI 标注）；表格/图片之后。
- 3up 里**空单元格不生成图注**。

**尺寸算法**（沿用 P0a，只把宽度来源参数化）：
- 宽 `emu_from_cm(w_cm)`；高 = `宽 * px_h / px_w`（四舍五入）；
- 若高 > `emu_from_cm(20.0)` → 宽按高上限反算；
- 3up 额外上限：高 > `emu_from_cm(10.0)` 时按 10cm 反算（避免一页放不下三格）。

**统计**：`FillStats.figures` 计"图片张数"（items 总数）；新增 `FillStats.captions`（图注段数）；`tables` 不计 3up 图桌（图桌不是业务表格）。

**表格首列底纹**（`table.first_col_fill`，B1 只留字段、B2 落渲染）：
- 业务表格的**数据行首列**单元格 `tcPr` 追加 `<w:shd w:val="clear" w:color="auto" w:fill="{first_col_fill}"/>`；表头行不加。
- `first_col_fill` 为空串时不输出该元素（便于以后关掉）。

## 8. 已知风险

1. **`sectPr` 子元素顺序**：`headerReference`/`footerReference` 必须在 `pgSz` 之前，否则 Word 可能报文档损坏。验收只能靠 XML 断言 + WPS 打开（本机可行）。
2. **TOC 域**：WPS/Word 打开时会弹"更新域"或自动更新；`updateFields=true` 已在 settings。LibreOffice 不更新 TOC，不作为验收渲染器。
3. **3up 图桌的 `tables` 计数**：必须按"含 `BidTableHeader` 的表"计，否则 golden 期望值会对不上。
4. **旧样本 `p0a-sample.docx` 会变**（图注/页眉加入后字节变化），其 sha 与页数基线需在 B4 重记。
5. **真实语料不得入库**：天长 6 份 python-docx 标书只在 `target/tmp/**` 使用；golden 一律合成内容。
6. **B1→B2 中间态**：B1 交付时旧 `fill.rs` 不认 `BID_FIGURE_3UP/WIDE`，会把这两个空段落留在成品里。这**不会**让旧 `verify` 变红（禁用词表未含它们、`BidFigureCell` 空段落不计数），但 B2 必须把两个 block 加入删除列表并扩禁用词表。
7. **样式数变化波及 `template_gen` 自身测试**：10 → 13 后旧断言"恰好 10"必红，B1 必须同片改掉。
