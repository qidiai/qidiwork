# 需求 R5：会话续接转录回放（v0.1.3 候选）

> 建立：2026-09-21（用户提出）| 优先级：高 | 来源：实测发现"续接只恢复上下文、不回放聊天记录"
> 方案：GUI 直读内核会话文件（零内核改动、零协议改动）

## 需求描述
关闭程序重开后，点击历史会话续接时，**聊天区回放最近的转录消息**；更早的消息折叠成一条横幅按钮，客户需要时点「加载全部」（或「加载更早 N 条」）展开。历史会话列表同时升级显示真正的会话标题。

## 技术事实（指挥官已核实）
- 转录文件：`~/.qidi/sessions/<urlencoded-cwd>/<session-id>/chat_history.jsonl`
  - 每行一条消息：`{"type":"system|user|assistant", "content": <string|content-blocks>}`（Anthropic 标准格式，与实时流同构——前端可复用现有渲染器）
  - 路径段编码 = `urlencoding::encode(cwd)`（如 `G:\qidicode` → `G%3A%5Cqidicode`）
- 元信息：同目录 `summary.json` — 含 `session_summary`（**会话标题**）、`num_messages`、`current_model_id`、`updated_at`
- GUI 登记簿已有 `session_id + cwd`（persist.rs）——定位文件所需字段齐备
- 大会话实测可达 4010 条消息 → 必须尾部截取，禁止全量默认加载

## 功能规格

### 1. 后端（gui/src-tauri/src/transcript.rs 新文件）
- `session_transcript_tail(session_id, cwd, limit=50) -> TranscriptPage { messages: Vec<RawMessage>, total_messages: u64, truncated: bool }`
  - 定位 chat_history.jsonl（QIDI_HOME 优先，否则 `~/.qidi`）；文件不存在 → 空 page + `missing: true`
  - **尾部读取**：文件 >2MB 时 seek 到末尾 2MB 再补齐边界行；解析 JSONL，丢弃解析失败的行（容错），取**最后 limit 条**；`total_messages` 从 summary.json 读（比逐行数省）
  - 消息原样返回（serde_json::Value 数组），前端负责渲染
- `session_transcript_earlier(session_id, cwd, before: u64, limit=200) -> TranscriptPage` — 从文件头读到 `before` 偏移（或全量读后切片，注意 2MB 分块推进直到凑够 limit 条更早消息）
- `session_summary(session_id, cwd) -> {title, num_messages, updated_at}` — 历史列表标题升级用
- lib.rs 注册三命令；**不新增任何依赖**（serde_json/reqwest 已有；urlencoding 逻辑手写——查 gui Cargo.toml，若无 urlencoding crate 则手写 percent-encode 与内核 `urlencoding::encode` 对齐：非 [A-Za-z0-9-_.~] 一律 `%XX` 大写十六进制）

### 2. 前端
- **续接时**（session_resume 成功后）：调 `session_transcript_tail(id, cwd, 50)`，把消息**按原顺序**注入该会话的转录区顶部（复用现有消息渲染管线，system 消息可跳过或折叠），然后正常进入实时流
- **折叠横幅**：当 `total_messages > 已显示数` 时，转录区顶部显示横幅：「已加载最近 50 条 · 共 4010 条 [加载全部]」；「加载全部」调 earlier(0) 补齐前面所有（大会话 >10MB 时先确认弹层提示可能较慢）；横幅消失
- **历史列表标题**：loadHistory 时并行拉 summary（50 个会话以内全拉，超出只拉前 50），`title` 字段优先用 `session_summary`，无则回退 cwd 目录名
- 崩溃恢复（agent_recover）路径同样注入 tail 回放
- 全部失败静默降级（回放缺失不影响续接本身）

### 3. 明确边界
- 只读不改：GUI 对 sessions 目录只读（写仍归内核）
- 不回放 tool 请求的弹窗重复触发：渲染为文本，不走权限管道
- v0.1.2 的 updater/diag/auth 文件不碰

### 验收（编码手自测）
- vue-tsc 0 错误；gui cargo check 0 新告警
- 单测：percent-encode 与样例 `G:\qidicode → G%3A%5Cqidicode` 一致；JSONL 容错（含坏行）解析
