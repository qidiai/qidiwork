免费额度速查表：魔搭 / Google AI Studio / 各家 API 中转（2026-10 实测）

发布于 2026-10-21实测 · 额度 · 备忘

全部数据由我们用真实 key 实测（2026-10-21），不是抄官方文案。平台政策随时会变，以你开通当天的实际页面为准。

一、魔搭 ModelScope（阿里）

  • 额度形态：按日发放「魔粒」，个人账号每天约 250 魔粒；每日 0 点刷新。
  • 耗尽表现：API 返回 429 insufficient balance；此时网页端账户可能显示已到账，但调用仍失败——这是「额度按模型/按日结算」与「账户余额」两件事。
  • 实用建议：多账号各持一把 key 轮换，配合自动降级；单账号的日额度扛不住长时间编码。

二、Google AI Studio（Gemini API）

  • 免费档可用：gemini-3.5-flash、3.5-flash-lite、3.6-flash、3.7-flash、3.8-flash、gemma-4 系列（实测 200）。
  • 需要付费额度：gemini-4-argon、gemini-3.1-pro-preview——免费档直接 429，需在 AI Studio 开通计费。
  • 网络前提：国内直连不通，需要海外出口；免费档额度按日重置，重度测试当天就会打光。
  • 成本参考：Argon 官方价约 $2 / 百万输入 token。

三、API 中转平台

  • APIGOTO：注册送 1 亿 token（30 天），实名认证再送 4 亿；平台价约为官方的 0.8 折，另有订阅制（详见这篇实测）。
  • 中转平台多如牛毛：额度、价格、稳定性差异极大，选之前先小额度试；本表只收录我们自己在用且实测过的。
  • 判断真假：不要看名字，看行为——同一提示词下 prompt_tokens 是否恒定（tokenizer 恒差）、几道硬题（9.11 与 9.9、strawberry 的 r、24 点、日期推算）能否全对。

四、避坑清单

  1. 额度≠余额：日额度、订阅额度、API 余额是三套账本，别用网页上的数字推断 API 能不能调。
  2. 中转有风险：模型注水、突然跑路、key 被封都发生过；重要任务留官方直连兜底。
  3. 别把免费额度当生产容量：免费档适合验证与小流量，生产要算清单位成本与限流。

小结

免费额度的正确用法是「低成本验证 + 高峰分流」，而不是「长期白嫖」。把额度当成可替换的临时资源，系统里永远留一条付费或备用通道，才不会被某一家卡住。
