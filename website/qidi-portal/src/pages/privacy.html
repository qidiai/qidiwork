1. 适用范围

本政策适用于启迪 QIDI AI（qidiai.ltd）运营的下载中心（qidiwork.qidiai.ltd）、门户网站（www.qidiai.ltd），以及上述网站分发的 QidiWork 桌面工作台与 QIDI Code 软件（以下合称"本软件"）。本软件以 Apache License 2.0 开源，源代码公开可审阅。

2. 本软件如何处理数据

  • 本地优先：本软件的配置、会话记录与模型 API Key 均保存在您本机的用户数据目录中，不上传至我们的服务器。
  • 账号登录（可选）：使用协同模型时，通过 QIDI AI 账号体系（api.qidiai.ltd）进行 OAuth 授权，仅获取调用模型所需的访问令牌；不登录亦可使用自备 API Key。
  • 对话内容：您输入的内容按设置面板中所选的模型服务商（如 OpenAI、Anthropic、xAI 等）直接发送，由对应服务商依据其隐私政策处理；我们不经手、不存储对话内容。
  • 更新检查：本软件会向 qidiwork.qidiai.ltd 请求版本清单（含版本号、下载地址与校验值）以提供应用内更新，该请求不携带设备或使用数据。
  • 无遥测：本软件不含使用情况统计、崩溃上报或行为跟踪代码。

3. 网站如何处理数据

下载中心与门户使用自建服务统计页面访问与入口点击：不设置跟踪 Cookie，不使用 localStorage 跟踪，不保存原始 IP 地址与完整浏览器标识，仅以当日匿名去重方式估算访客数，数据保留 90 天。统计尊重浏览器的 Do Not Track 与 Global Privacy Control 设置，您也可以点击页脚的「关闭访问统计」退出统计。

4. 第三方服务

您选择的模型服务商、以及为分发软件而使用的托管服务，按其各自的隐私政策处理相关数据。安装包提供 SHA-256 校验值供完整性核验。

5. 数据安全

本软件不收集个人数据，因此不存在集中式的个人数据存储。您的 API Key 与令牌仅存于本机，请在共享设备上谨慎保存，并及时在设置面板中清理。
