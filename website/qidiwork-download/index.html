安装指引

1

SmartScreen 提示：下载后若 Windows 弹出蓝色「Windows 已保护你的电脑」提示，点击「更多信息」→「仍要运行」即可——这是未购买代码签名证书的正常现象，可通过上方 SHA-256 校验安装包完整性。

2

管理员授权：安装过程会弹一次 UAC 窗口，点「是」即可；AI 内核已随安装包平铺分发，无需单独下载配置。

3

首次启动：安装完成后程序自动启动，在设置面板填入模型 API Key（或登录 QIDI 账号使用免费协同模型）即可开始工作。
